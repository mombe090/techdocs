# Icons & Emojis

Material for MkDocs includes support for thousands of icons and emojis.

## Using Icons

Material for MkDocs uses [Material Design Icons](https://materialdesignicons.com/), [FontAwesome](https://fontawesome.com/icons), and more.

### Material Icons

- :material-account-circle: Account
- :material-home: Home
- :material-heart: Heart
- :material-star: Star
- :material-check: Check
- :material-alert: Alert
- :material-information: Information
- :material-cog: Settings

### FontAwesome Icons

- :fontawesome-brands-github: GitHub
- :fontawesome-brands-python: Python
- :fontawesome-brands-docker: Docker
- :fontawesome-brands-linux: Linux
- :fontawesome-solid-code: Code
- :fontawesome-solid-terminal: Terminal
- :fontawesome-regular-file-code: File

## Using Emojis

Standard emojis are also supported:

- :smile: :heart: :rocket: :fire: :tada:
- :thumbsup: :thumbsdown: :eyes: :bulb: :zap:
- :100: :star: :sparkles: :heavy_check_mark: :x:
