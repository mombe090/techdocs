# Icônes & Emojis

Material for MkDocs inclut le support de milliers d'icônes et d'emojis.

## Utilisation des Icônes

Material for MkDocs utilise [Material Design Icons](https://materialdesignicons.com/), [FontAwesome](https://fontawesome.com/icons), et plus encore.

### Icônes Material

- :material-account-circle: Compte
- :material-home: Accueil
- :material-heart: Cœur
- :material-star: Étoile
- :material-check: Vérifier
- :material-alert: Alerte
- :material-information: Information
- :material-cog: Paramètres

### Icônes FontAwesome

- :fontawesome-brands-github: GitHub
- :fontawesome-brands-python: Python
- :fontawesome-brands-docker: Docker
- :fontawesome-brands-linux: Linux
- :fontawesome-solid-code: Code
- :fontawesome-solid-terminal: Terminal
- :fontawesome-regular-file-code: Fichier

## Utilisation des Emojis

Les emojis standard sont également supportés :

- :smile: :heart: :rocket: :fire: :tada:
- :thumbsup: :thumbsdown: :eyes: :bulb: :zap:
- :100: :star: :sparkles: :heavy_check_mark: :x:
