## 🔑 Key Concepts

### File Naming
- `page.md` = English (default)
- `page.fr.md` = French translation
- `page.es.md` = Spanish translation

### URLs
- `/` = English
- `/fr/` = French
- `/es/` = Spanish

### Commands
```bash
uv run mkdocs serve   # Preview
uv run mkdocs build   # Build
```
